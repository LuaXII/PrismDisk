Features

Everything you need to win back space.

Built for the moment your drive turns red: find what is big, what is duplicated and what can go, then clean it up safely.

Instant scans, straight from the MFT

Instead of asking Windows about every folder one by one, PrismDisk reads the NTFS Master File Table in large sequential chunks. A full terabyte drive is mapped before most tools have finished their first folder.

PrismDisk MFT scan3.5 s
PrismDisk folder walk~1 min
Typical folder-by-folder toolsseveral min

Treemap & sunburst

Spot the giants at a glance. Hover to inspect, click to jump to it in the tree, double-click to zoom in.

Smart cleanup

Finds temp folders, shader and browser caches, package caches, crash dumps and the Recycle Bin. One click empties them.

Duplicate finder

Compares file contents, so renamed copies are caught too. Groups are ranked by how much space the extra copies waste.

Largest files & search

Wildcards, path patterns, ext:iso filters, minimum size and “older than” filters across millions of files.

Safe by design

Deletes go to the Recycle Bin unless you say otherwise, and critical system folders are protected.

Photos & videos, minus the copies

A fast gallery of every picture and clip on the drive, grouped by month or folder, with a timeline, a full-screen viewer and filters for screenshots, blurry shots and large videos. PrismDisk looks at what each photo actually shows, so the copy a chat app shrank, re-compressed, rotated or renamed still lands next to the original, and it suggests the best one to keep.

Protects encrypted vaults

VeraCrypt and TrueCrypt containers are recognized, even when renamed, and deleting one takes an extra confirmation.

Updates itself

New versions download in the background. One click restarts into the update, with release notes built in.

Light and native

One small process with no browser engine inside. Right-click any folder in Explorer to analyze it, and import or export WizTree CSVs.

FAQ

Questions, answered

Why does PrismDisk ask for administrator rights?

Reading the Master File Table directly needs raw access to the drive, which Windows only grants to administrators. Without it, PrismDisk still works using a slower folder-by-folder scan.

Is it safe to delete what it finds?

PrismDisk only deletes what you choose, asks first every time, and sends files to the Recycle Bin unless you pick “Delete permanently”. Smart Cleanup only targets caches and temp folders that apps rebuild on their own, and critical system folders can't be deleted at all.

How do updates work?

When it starts, PrismDisk checks GitHub for a newer release and downloads it in the background. A banner shows the release notes, and one click on “Restart & update” installs it and reopens the app with your settings kept.

Does it send any data anywhere?

No. Scans stay on your PC. The only network request is the update check against GitHub's public release list.

Is it really free?

Yes. PrismDisk is open source under the MIT license, with no ads, accounts or paid tiers.

How do I uninstall it?

Use Settings → Apps → PrismDisk, or run “Uninstall PrismDisk” from the install folder. It removes the app, shortcuts and Explorer integration and never touches your files.
